一、架构总原则：为什么不做"一套万能模板"

把 A 股与美股塞进同一张表，结果必然是对两边都不好用。正确做法是拆成三层——上层同构、中层替换、下层可插拔。

通用层 · 直接迁移
基本面结构、估值方法选择、风控与复盘框架。A 股与美股逻辑同构，模板字段一字不改。
市场适配层 · 必须替换
资金流与情绪指标。A 股用主力资金/两融/北向；美股用 13F/空头持仓/期权流。字段名相同，取数器不同。
数据源层 · 可插拔
同一字段挂不同数据源。模板结构不动，换市场只换 adapter。
判断标准：一个指标若在两地含义相同（如毛利率、ROE），进通用层；若含义或可得性不同（如"主力资金"在美股根本不存在），进适配层。

二、模板 A · 个股深度研报回答：为什么会有人买它

核心交付不是资料堆砌，而是一句话——"买它本质上是在买 ____"。这句话必须能被某个具体数据推翻，否则它不是投资逻辑，是情绪。

字段组指标 / 内容口径与判据在选股中的作用填充
A1 公司核心信息名称 · 代码 · 市场 · 行业 · 市值 · 主营代码需带市场后缀（002422.SZ / NVDA.US）身份锚定，防止同名主体混用自动
A2 业务结构拆解分部收入占比 · 分部增速 · 分部毛利率至少拆到"主导业务 / 增长业务 / 衰退业务"三层识别哪块业务决定估值，避免用合并报表掩盖结构自动
A3 行业格局行业阶段 · 行业空间 · 竞争强度 · 公司位置导入 / 成长 / 成熟 / 下行；龙头 / 细分龙头 / 追赶者 / 边缘决定该给多少估值溢价手填

三、模板 B · 估值定价研报回答：股价里已经装了什么

这一层最容易做错——把 PE 当成"贵贱开关"。它的真正用途是反推市场共识：高 PE 不是卖出信号，而是"市场已把高增长定价进去，你只能赚超预期的钱"。

字段组指标口径与判据在选股中的作用填充
B1 公司类型判定高成长 / 稳健成长 / 周期 / 价值 / 资源 / 平台 / 金融类型决定方法，不可混用选错类型 = 后续全错半自动
B2 估值方法选择PE / PEG / PB / PS / EV-EBITDA / 分部 / DCF / 股息率必须写明"为什么这个方法最适合这家公司"避免生搬硬套手填
B3 当前估值PE(TTM) · PB · PS · PEG · EV · 股息率标注 TTM / 静态 / 动态口径横向比较的基准自动
B4 历史分位PE 分位 · PB 分位（3 年 / 10 年）<30% 偏低 · 30–70% 中性 · >70% 偏高纵向定位。3 年算不准，务必取 10 年自动
B5 行业横向同业 PE / PB / EV-EBITDA 对照跨公司比 PE 前先核对财年口径识别"相对贵/相对便宜"自动

B8 杀估值触发增速下修 / 景气拐点 / 竞争恶化 / 风险偏好下降 / 政策冲击需可观测、可证伪下行风控清单手填

四、模板 C · 交易计划与复盘迭代回答：我到底执行了没有

前两份模板产出"想法"，这一份产出"动作"与"修正"。关键分叉：你没执行计划，是因为计划错了，还是因为你手软了？前者调参数，后者调权限——两者需要完全相反的修正动作。

字段组指标 / 内容口径与判据在选股中的作用填充
C1 前提声明市场环境 · 风险偏好 · 资金量 · 期限前提缺失则拒绝给出操作建议所有阈值的锚点，无前提的风控是空话手填
C2 入场条件触发信号 · 当前估值分位 · 左侧/右侧左侧潜伏与右侧验证必须显式区分杜绝"看着不错就买"半自动
C3 止损技术位止损 · ATR 倍数止损 · 逻辑止损ATR 决定宽度，不用整数拍脑袋；逻辑止损优先级高于价格止损把最大亏损锁定在开仓前半自动
C4 止盈分批止盈 · 移动止盈按估值分位与目标区间分档解决"赚过又还回去"半自动
C5 仓位单笔风险敞口 = 总资金 × 风险预算由止损宽度反推仓位，而非先定仓位再找止损唯一真正控制回撤的字段半自动
C6 持有期监控跟踪指标 + 验证周期每项指标写明"何时看、看到什么算变坏"把持有变成可执行的观察清单手填
C7 复盘 · 纪律计划 vs 实际成交 · 偏差归因未执行硬止损 → 纪律分归零，触发系统接管区分"计划错"与"手软"自动
C8 复盘 · 逻辑买入假设是否被证伪逐条假设给"已验证 / 未验证 / 已证伪"逻辑止损的依据半自动
C9 复盘 · 情绪每次手动加减仓时的情绪标签贪婪 / 恐惧 / 焦虑 / 不甘 / 从众识别情绪是否主导了操作手填
C10 复盘 · 参数止损/止盈/仓位网格寻优（Walk-Forward）目标函数建议用卡玛比率 = 年化收益 / 最大回撤把实盘结果变成系统进化的燃料自动
