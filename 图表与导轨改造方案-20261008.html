现状判定的两个硬约束（决定方案形态）：
① 前端是原生 Canvas 自绘、零 CDN 依赖（README 明确写"无任何 CDN 依赖"）。所有新增图形必须继续手绘，不能引入 ECharts——否则会破坏离线可用性与 CSP default-src 'self'。
② 服务端版与静态版必须同构。lib/ 下的模块会被 build-static.js 打包进 docs/bundle.js。新增指标只能写在 lib/，且不得引用 Node 专属 API（除非用 @node-only 包起来）。

二、修改目标三条，按性价比排序

目标 1 · 把"算了没画"的全部画出来
系统已经算出了 KDJ、RSI、唐奇安、成交量均线、布林带宽分位，但用户在图上看不到。 这些是零新增数据成本——只加绘图代码，不改数据层。
衡量标准：新增 7 个可视元素，数据层零改动。
目标 2 · 导轨从"参考线"升级为"决策轨道"
现在的导轨只是一条画到最后一根 K 线的通道。趋势轨道的核心价值在于 回答"未来通道在哪里"——当前实现缺三件事：向未来外推、突破点标记、参数可调。 信号引擎已经判定了突破，但图上没有任何标记，用户必须自己去读文字。
衡量标准：轨道外推 ≥20 根；突破点有图上标记且可点击；窗口与 k 值可手调。
目标 3 · 从"单股详情"扩展到"大盘 / 板块 / 自选股"三层
当前系统只有个股视角。但同一根 K 线在不同市场环境下含义完全不同—— 个股跌破布林下轨，在指数同步下跌时是"随大盘"，在指数走强时才是"个股走弱"。 没有大盘与板块视图，就无法区分这两者。
衡量标准：新增大盘视图与板块视图各 1 个；个股页新增"相对指数"叠加。

三、新增图形类型四组

A 组 · 主图（价格区）

序图形数据状态说明与呈现方式
A1周线 / 月线 K 线源已支持 数据源已有 klt=week/month 参数，只需在 UI 加周期切换按钮组（日/周/月）并透传。 周月线的均线周期应同步换算（MA5 周 = MA25 日），否则均线会失去意义。
A2唐奇安通道线已算未画 donchian(kline, 20) 已算出上下沿。在主图以阶梯线绘制（不是平滑曲线——唐奇安的本质是"过去 N 日极值"，用平滑线会失真）。 阶梯在创新高/新低时才跳变，视觉上能直接看出"区间何时被突破"。
A3Keltner 通道（ATR 通道）新增 中轨 = EMA20，上下轨 = 中轨 ± 2×ATR(14)。与布林的区别：布林用标准差（对跳空敏感），Keltner 用 ATR（对跳空稳健）。 两者叠加时，"布林在 Keltner 内侧"= 波动收窄（变盘临近）——这是一个高价值信号，值得单独出规则。
A4关键价位标注已算未画 keyLevels() 已算出支撑/阻力。在图上画水平虚线 + 右侧价格标签，按距现价远近分档着色。
A5安德鲁叉 Pitchfork新增 取三个枢轴点（高-低-高 或 低-高-低）画三条平行趋势轨道。可选功能——枢轴点自动识别容易出错，建议先只做手动选点。

B 组 · 副图（新增独立区域）

当前副图只有 MACD 一个区。建议改为可堆叠的副图栈——每个副图高度可折叠，用户勾选哪些就显示哪些。

序副图数据状态说明
B1KDJ 副图已算未画 三线 K/D/J + 超买(80)/超卖(20) 参考线 + J 值 0/100 极值区着色。J 值已参与信号判定，画出来用户才能验证信号对不对。
B2RSI 副图已算未画 RSI14 单线 + 30/70 参考线 + 超买超卖区着色。可选叠加 RSI6/RSI24 做快慢对比。
B3成交量均线已算未画 在现有量区叠加 MA5/MA20 均量线。avgVol5/avgVol20 已有数值，扩展成序列即可。
B4轨道宽度带已算未画 布林带宽（上轨−下轨）/中轨 的时序曲线 + 近 120 日分位带。 带宽收窄至 20% 分位以下 = 变盘临近——这是布林最有价值的用法，现在只有一行文字。

C 组 · 导轨增强本方案的核心

序增强项说明与呈现方式
C1导轨向未来外推 当前导轨只画到最后一根 K 线。趋势轨道的核心价值是回答"未来通道在哪里"。
实现：按回归斜率线性外推 N 根（建议 20 根），画成虚线并在末端标注通道值。
视觉区分：已实现区实线、外推区虚线——不能让人误以为外推是既成事实。
外推同时要给出置信衰减：外推越远越不可靠，建议用透明度渐变或加"±1σ"喇叭口。
C2多窗口导轨叠加 现在自适应算法在 60/45/30/20 里只挑一个。建议允许同时显示 2–3 条不同窗口的导轨（如 60 日中期 + 20 日短期）。
价值：当短期导轨与中期导轨方向一致 = 趋势共振；方向背离 = 趋势可能转折。这是当前单一导轨给不出的信息。
C3突破 / 触及标记 信号引擎已判定"突破上轨""跌破下轨""沿上轨运行"等 10 类轨道规则，但图上没有任何标记。
实现：在对应 K 线上画三角标记（▲ 向上突破 / ▼ 向下突破），hover 显示该信号的方向、强度、权重、数据依据。
点击标记应跳转到信号面板对应条目——这是把图形与文字结论连起来的关键。
C4斜率可视化 现在斜率只是文字（"斜率 −7.39%/20日"）。建议在导轨末端画斜率指示箭头，箭头长度正比于斜率绝对值，方向即趋势方向。
颜色遵循 A 股惯例：向上红、向下绿（与美股相反，不要弄反）。
C5导轨参数手调 现在窗口与 k 值完全自适应、用户无法干预。建议加一个折叠面板：窗口（20/30/45/60/120）+ k 值（1.0–3.0 滑块）+ 是否外推 + 外推根数。
注意：自适应值仍作为默认，手调是覆盖。参数应写进 URL hash 或 localStorage，刷新后保留。
C6通道位置连续色带 在 K 线区右侧加一条垂直色带，用颜色表示价格在通道中的位置（上轨附近=红、中轨=灰、下轨附近=绿）。比单点位置条更能表达"最近在通道里的移动轨迹"。

序视图现状内容
D1大盘 / 指数视图完全缺失 上证指数 / 深证成指 / 创业板指 / 沪深300 的 K 线 + 布林 + 回归导轨 + 宽度带。

D3自选股轨道状态一览缺失 在自选股列表每行加：迷你 K 线缩略图（sparkline）+ 轨道状态徽标（上升/下降/水平 + 通道位置）。
让用户不用逐个点开就能看出"哪只在通道下沿、哪只在通道上沿"。

这是区分"个股走弱"与"随大盘下跌"的唯一手段。

四、导轨呈现方式三层轨道体系

当前是"一条自适应通道"。建议改为三层时间尺度轨道 + 外推区，让用户一眼看到短期波动在中期通道中的位置。

层周期轨道类型作用
短期轨20 根唐奇安区间 + 布林区间是否被突破、波动是否收窄（箱体交易）
中期轨60 根回归导轨（现有默认）趋势方向与通道斜率（趋势跟随）
长期轨120 根回归导轨大级别趋势与通道，判断中期轨是否只是长期轨内的反弹
外推区未来 20 根中期轨外推（虚线）回答"未来通道在哪里"——支撑/压力位的动态预测

九、期望结果可验收的标准

9.1 展示效果

维度预期
信息密度单屏内可同时看到：三层轨道 + 突破点 + 三个副图。用户不必在标签页之间来回切
一眼可读看导轨颜色即知趋势方向；看通道位置色带即知"偏贵还是偏便宜"；看突破标记即知"信号在哪天触发"
推演与事实分离外推区必须是虚线且透明度渐变——不能让人把推演当既成事实
图文一致图上每个标记都能在信号面板找到对应条目；反之亦然。点击标记可跳转
口径可追溯每个新图形旁标注参数与数据时点（如"回归导轨 60 根 · k=2 · 截至 2026-10-08 15:00"）

十、分期实施建议按性价比排序

期内容成本为什么排这个位置
P0 B1 KDJ 副图 · B2 RSI 副图 · B3 成交量均线 · A2 唐奇安阶梯线 · A4 关键价位标注 低 全部是"算了没画"，数据层零改动。收益最直接：用户终于能看到信号引擎判定的依据
P1 C1 导轨外推 · C3 突破标记 + 点击跳转 · C4 斜率箭头 中 把导轨从"参考线"变成"决策轨道"。突破标记让图文打通，这是体验提升最明显的一步
P2 A1 周月线切换 · C5 参数手调 · 十字光标接线 · 区间缩放 中 交互能力补齐。周月线的数据源已就绪，成本主要在均线周期换算的正确性验证
P3 B4 带宽带 · A3 Keltner 通道 · C2 多窗口导轨 中 新增指标与规则。必须同步补测试——新规则会改变评分结果，没有回归测试会静默影响所有历史结论
P4 D4 个股 vs 指数叠加 · D3 自选股轨道徽标 高 先做 D4 是因为它产生决策价值（区分个股走弱 vs 随大盘）。D3 是体验优化
P5 D1 大盘视图 · D2 板块视图 高 最后做。板块数据有 CORS 问题需要先解决；且只有在 D4 做完后才真正有用

十一、风险与边界

风险触发场景应对
外推被当成事实用户看到虚线通道末端，以为是"目标价" 虚线 + 透明度渐变 + 末端标注"推演，非预测"；报告引用时必须写明"基于 N 日回归外推"
多图层性能Canvas 自绘 + 10 个图层 + 250 根 K 线 单次重绘路径数上限；副图栈按需渲染（未勾选不计算）；缩放时用降采样
新增规则改变评分新轨道规则纳入权重后，同一标的评分变化 必须补回归测试：记录一批标的在改动前的评分基线，改动后逐项比对差异并解释
静态版 CORS板块/指数接口无 CORS 方案阶段先验证；必要时构建时预生成快照，或明确标注"静态版不支持板块视图"
均线周期换算错误周线模式下沿用日线 MA5 这是最容易出错且最难发现的一类 bug（图看起来正常，含义完全错）。必须有断言测试
红绿反转照搬国际惯例把上升画成绿色 A 股红涨绿跌。新增颜色变量时集中定义，不散落在各绘图函数里
图层叠加遮挡布林 + Keltner + 唐奇安 + 导轨同屏 分层透明度；提供"仅显示当前关注图层"的快捷切换
一条不能省的工程要求：本项目的既有代码在"静默失败"上踩过多次坑 （K 线为空画白板、导轨对齐隐式契约、NaN 污染值域），源码注释里都留了记录。 新增图形必须沿用同一套防御规范：任何数组为空、任何值为 NaN、任何宽度为负， 都要画一句人话而不是留白。"图是空的"必须有理由可见——否则新图层会成为下一批静默故障的来源。
现状判定依据：仓库 github.com/Martens-100/stock-sentry（main 分支，2026-09-17 最后更新）源码逐文件核对， 结合线上页面 stocksentry-ashare.app.workbuddy.host 的实际渲染结果。
核对到的关键事实：chartOpts 实际仅 4 个开关（boll/rail/ma/cross）；KDJ、RSI、唐奇安、avgVol、布林带宽均已计算但未绘制； grep 大盘/指数/板块关键词在 public/ 下命中数为 0；lib/source.js 已含 klt 周期参数但 UI 未透传。
